# MedPlac

Aplicativo desenvolvido como projeto acadêmico com o objetivo de facilitar o acesso aos serviços de saúde.

## Funcionalidades

- Login
- Cadastro
- Agendamento de consultas
- Busca por médicos
- Histórico Médico
- Botão de emergência
- Inteligência Artificial
- Interface acessível

## Tecnologias

- React
- Lovable
- Figma
- Google Sites
